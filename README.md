# One More

***Press your luck.***

One big button. Every press adds one, and every press quietly raises the odds that it's your last. Beat your best, chase hidden tiers, and play live with friends using a room code.

**Play:** https://notarqen.github.io/one-more/

- Single `index.html`, no build step.
- Multiplayer is peer-to-peer over WebRTC ([PeerJS](https://peerjs.com)); the public PeerJS server only handles matchmaking.
- Best score, name and run history are stored in your browser only.
